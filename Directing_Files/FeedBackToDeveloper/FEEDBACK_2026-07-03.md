## 피드백 내용

메인 Gameplay에서 카메라는 노트(캔들)의 위치와 입력 흐름에 따라 이동해야 한다.

| 항목 | 내용 |
| --- | --- |
| 시기 | 노트(캔들)의 위치에 따라 입력했을 때 |
| 위치 | 카메라 위치가 해당 노트(캔들)를 따라가며, 해당 노트(캔들)가 카메라 중앙에 올 수 있도록 이동 |
| 속도 | 이동 거리의 약 3/4 지점까지 먼저 이동한 다음, 목적지에 가까워질수록 점점 느려지는 방식으로 부드럽게 이동 |

## 원문

```text
- 메인 : 카메라 노트에 따라 이동해야함
1)  시기 : 노트(캔들)의 위치에 따라 입력했을때
2)  위치 : 카메라 위치가 해당 노트(캔들)이 카메라 중앙에 올 수 있도록 이동해야함
3)  속도 : 이동하는 속도의 경우 3/4정도 이동한 다음 목적지에 가까워질 수록 점점 낮아지는 방식으로 부드럽게 이
```

## 의도

- 플레이어가 입력한 노트(캔들)를 화면 흐름 안에서 명확히 따라갈 수 있어야 한다.
- 입력 피드백이 단순 판정 텍스트에만 머무르지 않고, 카메라 이동으로도 전달되어야 한다.
- 카메라 이동은 즉시 튀는 방식보다 감속이 느껴지는 부드러운 방식이 어울린다.

## 개발자 결정 영역

- 이동 속도 구현 방식
- 보간 또는 감속 방식
- 이동 범위
- 플레이 가독성을 해치지 않는 보정 방식

# FeedBackToDeveloper

## 목적

이 폴더는 기획/디렉팅 관점에서 개발자에게 전달할 피드백을 모으는 공간이다.

## 기록 기준

- 구현 방식이나 코드 구조를 직접 지정하지 않는다.
- 기획 의도, 화면 구성, UX 흐름, 표현 기준, 확인 요청을 중심으로 작성한다.
- 개발자가 결정해야 할 항목은 `개발자 결정`으로 명확히 분리한다.
- 완료된 피드백은 관련 문서 또는 업데이트 로그에 반영 여부를 기록한다.

# StockRhythm Ideas

이 폴더는 StockRhythm의 기획 원문과 Project_RC에서 이어갈 방향성 문서를 관리한다.

## 원본 반영 파일

- `STOCK_RHYTHM_IDEA.md`
- `STOCK_RHYTHM_CONCEPT_UPDATE.md`

## 추가 제작 파일

- `STOCK_RHYTHM_DIRECTION_BRIEF.md`: 현재 적용할 게임 방향성 요약
- `STOCK_RHYTHM_MVP_TASKS.md`: MVP 제작 진행용 체크리스트
- `STOCK_RHYTHM_SAMSU_MVP_SPEC.md`: SAMSU 기준 MVP 판정/점수 사양
- `STOCK_RHYTHM_NEXT_PLANNING_ITEMS.md`: 추가로 진행해야 할 기획안 목록
- `STOCK_RHYTHM_PLAY_FLOW_UIUX.md`: 플레이 흐름과 UI/UX 화면 구성
- `STOCK_RHYTHM_DESIGN_GUIDE.md`: MVP 디자인 양식과 화면 톤 기준
- `STOCK_RHYTHM_SCENE_ELEMENT_LIST.md`: 씬별 후보 요소 목록

## 사용 기준

- 원본 문서는 보존 자료로 둔다.
- 실제 제작 판단은 `STOCK_RHYTHM_DIRECTION_BRIEF.md`를 우선 기준으로 삼는다.
- 구현 전 해야 할 일은 `STOCK_RHYTHM_MVP_TASKS.md`에서 관리한다.

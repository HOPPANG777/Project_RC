# StockRhythm Ideas

이 폴더는 StockRhythm의 기획 원문과 Project_RC에서 이어갈 방향성 문서를 관리한다.

## 원본 반영 파일

- `STOCK_RHYTHM_IDEA.md`
- `STOCK_RHYTHM_CONCEPT_UPDATE.md`

## 추가 제작 파일

- `STOCK_RHYTHM_DIRECTION_BRIEF.md`: 현재 적용할 게임 방향성 요약
- `STOCK_RHYTHM_MVP_TASKS.md`: MVP 제작 진행용 체크리스트

## 사용 기준

- 원본 문서는 보존 자료로 둔다.
- 실제 제작 판단은 `STOCK_RHYTHM_DIRECTION_BRIEF.md`를 우선 기준으로 삼는다.
- 구현 전 해야 할 일은 `STOCK_RHYTHM_MVP_TASKS.md`에서 관리한다.

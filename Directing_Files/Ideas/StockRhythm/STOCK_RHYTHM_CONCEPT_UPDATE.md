# Stock Rhythm Concept Update

작성일: 2026-06-27

이 문서는 기존 기획 이후 대화에서 새로 정리된 방향을 기록한다. 핵심은 Stock Rhythm을 투자 시뮬레이션이 아니라 차트 컨셉을 가진 낮은 난이도의 밈 리듬 게임으로 정의하는 것이다.

## 1. 핵심 포지셔닝

Stock Rhythm은 주식 차트의 상승, 하락, 급등락, 횡보 패턴을 BUY/SELL 2레인 리듬 노트로 변환한 차트 컨셉 리듬 게임이다.

- 투자 판단 게임이 아니라 차트 패턴 리듬 액션 게임으로 포지셔닝한다.
- 실제 수익률이나 투자 조언보다 패턴, 콤보, 피버, 점수, 밈 리액션을 중심에 둔다.
- 유저가 금융 지식 없이도 바로 이해할 수 있도록 낮은 난이도와 강한 시각적 피드백을 우선한다.
- 핵심 재미는 차트를 분석하는 것이 아니라 차트 움직임을 몸으로 치는 손맛이다.

## 2. 화면 및 입력 구조

기존의 복잡한 차트 레인 구조보다 세로 진행형 2레인 구조를 우선한다.

- 위 레인: BUY
- 아래 레인: SELL
- 차트 흐름은 중앙 또는 배경에서 세로 진행감과 함께 보여준다.
- 급상승 패턴에서는 BUY 연타 노트가 나온다.
- 급락 패턴에서는 SELL 연타 노트가 나온다.
- 횡보 구간은 노트를 줄여 쉬는 박자 또는 관망 구간처럼 느끼게 한다.
- 반전 구간은 BUY에서 SELL, 또는 SELL에서 BUY로 레인이 전환되는 재미를 만든다.

예시 패턴:

```text
급상승      -> BUY BUY BUY BUY
급락        -> SELL SELL SELL SELL
V자 반등    -> SELL SELL BUY BUY
쌍봉        -> BUY SELL BUY SELL
횡보        -> 드문드문 노트 또는 무입력
변동성 확대 -> BUY / SELL 교차 패턴
```

## 3. 밈 게임 방향

진지한 금융 게임보다 밈 캐주얼 리듬게임으로 밀어야 한다.

- 실패해도 스트레스보다 웃긴 리액션이 나오게 한다.
- 한 판이 짧고 쉽게 성공하도록 만든다.
- 숏폼 영상에서 3초 안에 이해되는 장면을 우선한다.
- 고난도는 기본 모드가 아니라 챌린지 또는 별도 난이도로 분리한다.

밈 패턴 예시:

```text
TO THE MOON      -> BUY 연타
PANIC SELL       -> SELL 연타
RUG PULL         -> BUY 중 갑작스러운 SELL 폭포
FOMO             -> 늦은 BUY 연타
DIP BUY          -> 하락 후 BUY 전환
SIDEWAYS HELL    -> 횡보 구간의 어색한 쉬는 박자
BAGHOLDER BLUES  -> 물림 상태를 표현하는 느린 패턴
```

## 4. 패러디 종목명

스테이지 이름은 실제 회사명을 직접 쓰지 않고, 실제 회사를 떠올릴 수 있는 가짜 종목명 또는 가짜 티커 패러디로 정한다.

예시:

```text
SOMSOMG   -> 삼성전자풍
NVIVIA    -> 엔비디아풍
TELSAR    -> 테슬라풍
APPLZ     -> 애플풍
GOOGOO    -> 구글풍
AMAZIN    -> 아마존풍
KAKAOOPS  -> 카카오풍
NAVAR     -> 네이버풍
HYUNDAZE  -> 현대차풍
SK HYPE   -> SK하이닉스풍
```

주의 기준:

- 실제 회사명, 실제 티커, 실제 로고는 사용하지 않는다.
- 실제 CEO 실명이나 실제 제품명을 직접 사용하지 않는다.
- 색상, 폰트, 아이콘을 실제 브랜드와 지나치게 유사하게 만들지 않는다.
- 회사 자체를 직접 조롱하기보다 시장 문화, 차트 움직임, 투자자 심리를 패러디한다.

## 5. 실제 차트 활용 방식

실제 차트를 참고하되 그대로 복제하지 않는다. 유저가 대략적인 분위기는 알아볼 수 있지만 정확한 종목과 가격은 알 수 없게 만든다.

- 실제 차트 복붙은 하지 않는다.
- 실제 차트에서 영감 받은 가상 차트로 재구성한다.
- 날짜는 연도 + 월 단위까지만 표시한다.
- 일 단위 날짜, 실제 가격, 실제 거래량 수치는 표시하지 않는다.
- Y축 가격은 제거하거나 Low / Mid / High 같은 추상 표현으로 바꾼다.
- 차트 모양은 스무딩, 노이즈, 리샘플링으로 변형한다.
- 거래량은 실제 수치가 아니라 열기 게이지나 리듬 강도처럼 표현한다.

게임 내 표기 예시:

```text
SOMSOMG
Inspired Pattern: 2021.01 - 2021.08
Pattern Type: Sideways Breakout
Difficulty: Easy
Mood: Box Hell Pop
```

## 6. 음악 방향

각 패러디 종목 또는 섹터 컨셉에 맞는 음악 장르와 스타일을 AI로 생성한다. 단, 아티스트 모방이 아니라 장르, 악기, BPM, 감정, 차트 상황 중심으로 프롬프트를 작성한다.

예시:

```text
SOMSOMG  -> 묵직한 K-electro, 반도체 공장 비트, 긴 횡보 후 빌드업
NVIVIA   -> glitch bass, cyber EDM, AI 과열 상승
TELSAR   -> synthwave rock, 로켓 변동성, 급등 후 급락
KAKAOOPS -> cute pop trap, 갑작스러운 dark drop, 플랫폼 이슈
APPLZ    -> clean future funk, 안정적인 중속 그루브
```

피해야 할 프롬프트:

```text
특정 아티스트처럼 만들어줘
특정 히트곡 느낌으로 만들어줘
특정 가수 목소리로 불러줘
```

권장 프롬프트:

```text
fast synthwave loop, 150 BPM, bright arpeggios, arcade racing energy
chaotic hyperpop rhythm loop, 160 BPM, short vocal chops, no lyrics
dark industrial EDM loop, distorted kick, panic selling mood
```

## 7. MVP 재정의

MVP는 다음 세 가지 스테이지로 반응을 검증한다.

1. TO THE MOON 계열: 쉬운 BUY 연타 중심
2. PANIC SELL 계열: 쉬운 SELL 연타 중심
3. RUG PULL 계열: BUY 진행 중 갑작스러운 SELL 폭포

검증 기준:

- 보는 사람이 즉시 차트 리듬게임이라는 것을 이해하는가
- 급등 BUY 연타와 급락 SELL 연타가 손맛 있게 느껴지는가
- 낮은 난이도에서도 콤보, 이펙트, 피버로 충분히 신나는가
- 실제 투자 조언처럼 보이지 않고 밈 게임처럼 보이는가
- 짧은 영상으로 공유하고 싶을 만큼 장면이 명확한가

## 8. 게임 화면 구조 업데이트

플레이 화면은 뒤 전광판, 가운데 주가 표시, 앞쪽 캔들 노트의 3층 구조로 정리한다.

- 전체 UI 인상은 순수 아케이드 화면보다 실제 거래창에 가깝게 만든다.
- 기존 `SCORE` 용어는 사용하지 않고 `PROFIT`으로 바꾼다.
- 좌우에는 호가창, BID/ASK, 뉴스 패널, 보조 차트, 거래량 패널처럼 보이는 정보 영역을 배치한다.
- 단, 실제 거래소, 증권사, 실제 종목, 실제 투자 수익처럼 보이지 않도록 모든 값은 가상 정보로 처리한다.
- 배경에는 큰 전광판을 둔다.
- 전광판 중앙에는 현재 주가를 크게 표시한다.
- 주가 뒤에는 해당 스테이지의 분위기를 보여주는 뉴스 이미지 또는 시장 이벤트 이미지를 흐릿하게 넣는다.
- 뉴스 이미지는 실제 언론사, 실제 인물, 실제 로고 없이 가상의 시장 뉴스 분위기로만 표현한다.
- 실제 클릭 기준이 되는 노트는 일반 아이콘이 아니라 진짜 차트의 캔들처럼 보이게 만든다.
- BUY 노트는 초록 상승 캔들, SELL 노트는 빨간 하락 캔들로 표현한다.
- 캔들 노트에는 몸통과 꼬리를 넣어 실제 차트 캔들처럼 읽히게 한다.
- 캔들 노트는 장식용 차트가 아니라 플레이어가 타이밍에 맞춰 클릭해야 하는 오브젝트다.

화면 역할:

```text
뒤 전광판       -> 시장 이벤트 / 뉴스 이미지 / 무대 분위기
중앙 주가 표시  -> 현재 스테이지의 가상 주가
좌우 거래 패널   -> 실제 거래창 같은 분위기와 정보 밀도
앞 차트 경로    -> 실제 플레이 레일
캔들 노트       -> 클릭 기준 오브젝트
PROFIT          -> 기존 SCORE를 대체하는 게임 성과 지표
```

예시 UI:

```text
SOMSOMG
1,248

초록 상승 캔들 = BUY 노트
빨간 하락 캔들 = SELL 노트
```

## 9. 플레이 규칙 업데이트

핵심 플레이 규칙은 다음 기준으로 정리한다.

### 캔들 노트의 BUY / SELL 결정

실제 차트를 그대로 쓰는 것이 아니라 게임용으로 수정한 차트를 사용한다. 수정된 차트의 캔들 흐름에 따라 각 캔들 노트를 BUY 또는 SELL로 결정한다.

- 상승 흐름 또는 매수 리듬으로 설계된 캔들: BUY 노트
- 하락 흐름 또는 매도 리듬으로 설계된 캔들: SELL 노트
- 원본 차트는 참고 자료이고, 최종 노트 배치는 게임성과 음악 리듬에 맞게 조정한다.

### 판정 타이밍 기준

플레이어가 누르는 타이밍은 캔들의 종가 지점을 기준으로 계산한다.

- 캔들 몸통 전체가 아니라 종가 위치가 판정 기준점이다.
- 판정선에 캔들의 종가 지점이 닿는 순간 BUY 또는 SELL 입력을 받는다.
- 상승 캔들과 하락 캔들 모두 종가 지점을 기준으로 동일하게 처리한다.

### PROFIT의 의미

`PROFIT`은 실제 수익 계산이 아니라 단순 점수다.

- 실제 투자 수익률이나 실제 손익으로 해석되지 않게 한다.
- `SCORE`라는 용어 대신 거래창 컨셉에 맞춘 점수 표현으로 `PROFIT`을 사용한다.
- PROFIT는 게임 내 성과 지표이며 실제 금전 보상과 무관하다.

### 실패와 콤보 처리

입력 정확도에 따라 PROFIT가 올라가고, 실수하면 콤보가 끊어진다.

- 정확한 입력: PROFIT 상승, 콤보 유지
- 애매한 입력: PROFIT 소폭 상승 또는 낮은 판정
- 실패 입력: 콤보 끊김
- 틀렸을 때 실제 손실처럼 큰 마이너스를 주기보다, 낮은 난이도 밈 게임 톤에 맞춰 콤보 중심으로 페널티를 준다.

### 스테이지 길이

스테이지 길이는 고정하지 않고 곡마다 다르게 설정한다.

- 곡 길이와 차트 패턴에 따라 30초, 60초, 그 이상도 가능하다.
- 짧은 밈 스테이지는 빠른 공유와 반복 플레이에 적합하게 만든다.
- 긴 스테이지는 특정 패러디 종목이나 보스 패턴용으로 사용한다.

## 10. 상세 룰 확정

추가 확정된 프로토타입 규칙은 다음과 같다.

### 10.1 캔들 노트 생성 규칙

캔들 노트는 현실 차트처럼 위아래로 왕복하다가 최종 방향이 결정되는 방식이 아니다. 게임용으로 수정된 차트에서 각 캔들은 단방향으로 오르거나 내려가는 리듬 오브젝트로 처리한다.

- 상승 캔들: 무조건 BUY
- 하락 캔들: 무조건 SELL
- 추세 전환, 고점, 저점에서 반대 입력을 요구하지 않는다.
- 큰 캔들을 롱노트나 특수 노트로 바꿀지는 추후 확장 항목으로 둔다.
- 유저는 캔들의 종가 지점까지 기다렸다가 누르는 것이 가장 유리하다.

### 10.2 종가 판정선 표현

판정 기준은 캔들의 종가 지점이다.

- 캔들의 종가 범위를 시각적으로 보여준다.
- 종가 범위는 해당 차트 색상의 명도를 낮춘 영역으로 표시한다.
- 상승 캔들과 하락 캔들 모두 종가 범위를 기준으로 동일하게 판정한다.
- 유저는 캔들 전체가 아니라 종가 범위가 판정선에 닿는 순간을 보고 입력한다.

### 10.3 입력 방식

키보드 입력은 양쪽 Shift 키를 사용한다.

- 왼쪽 Shift: BUY
- 오른쪽 Shift: SELL
- 모바일 입력은 아직 미정이지만, 기본 방향은 화면 양쪽 버튼이다.
- 롱노트 또는 홀드 입력은 현재 MVP 기본 규칙에는 포함하지 않는다.

### 10.4 판정 단계

판정 단계는 DJMAX 계열 판정 방식을 참고한다.

- 정확한 판정명과 판정폭은 추후 수치화한다.
- 현재 방향은 낮은 난이도 밈 게임에 맞춰 판정폭을 너무 빡빡하게 잡지 않는 것이다.
- 상업 구현 시 특정 게임의 명칭이나 수치를 그대로 복제하지 않고 자체 판정 체계로 정리한다.

### 10.5 PROFIT 계산식

`PROFIT` 점수 계산은 DJMAX 계열 점수 구조를 참고한다.

- `PROFIT`은 실제 손익이 아니라 단순 점수다.
- 입력 정확도에 따라 PROFIT가 증가한다.
- MISS 시 PROFIT를 실제 손실처럼 크게 깎는 방향은 우선 적용하지 않는다.
- 정확한 PERFECT/GOOD/MISS 점수, 콤보 보너스, 피버 배율은 추후 확정한다.
- 상업 구현 시 특정 게임의 계산식을 그대로 복제하지 않고 자체 점수식으로 정리한다.

### 10.6 콤보 / 피버

콤보와 피버의 세부 규칙은 아직 미정이다.

- 피버 게이지 충전 조건: 미정
- 피버 자동 발동 여부: 미정
- 피버 중 PROFIT 배율: 미정
- 피버 중 캔들 이펙트와 음악 변화: 미정

### 10.7 스테이지 구조

스테이지 구조는 아직 미정이다.

- 한 곡 안의 차트 구간 수: 미정
- 곡 길이에 따른 난이도 조정 방식: 미정
- 전광판 뉴스 이미지가 곡 전체 고정인지, 구간별 변경인지: 미정

### 10.8 MVP 패러디 종목

첫 MVP 후보 패러디 종목은 다음 세 개다.

```text
NVIVA
GAAGLE
SAMSU
```

각 종목의 차트 성격, 음악 장르, 대표 밈 패턴은 추후 확정한다.

### 10.9 UI 정보량

UI는 실제 거래창처럼 보이도록 정보량을 유지한다.

필수 또는 후보 정보:

- BID / ASK
- NEWS
- PROFIT
- 시가 총액
- 정확도
- COMBO
- FEVER
- 보조 차트
- 거래량 또는 호가 깊이처럼 보이는 패널

단, 정보 패널은 실제 거래창 느낌을 주기 위한 장식/게임 정보이며 실제 투자 정보가 아니다.

### 10.10 실패 조건

현재 MVP에서는 게임오버 조건을 두지 않는다.

- 끝까지 플레이 가능하게 만든다.
- 실수하면 콤보가 끊긴다.
- PROFIT 상승 효율이 낮아진다.
- 낮은 난이도 밈 게임 톤에 맞춰 강한 실패 페널티는 우선 제외한다.

### 10.11 안전 문구

안전 문구는 타이틀 화면 하단에 표시한다.

표시할 메시지 방향:

```text
실제 투자 아님
가상 차트 기반
PROFIT은 게임 점수
```

### 10.12 첫 프로토타입 범위

첫 프로토타입 범위는 아직 보류한다.

- 1스테이지 우선 제작 여부: 보류
- 3스테이지 동시 제작 여부: 보류
- 이미지/음악/노트 생성 자동화 범위: 보류

## 11. 현재 결론

Stock Rhythm은 금융 게임보다 차트 패턴 밈 리듬게임으로 가는 편이 더 강하다. 실제 종목은 직접 쓰지 않고 패러디 종목명과 변형된 월 단위 차트를 사용한다. 음악은 각 패러디 종목의 섹터와 차트 감정에 맞춰 AI로 생성하되, 특정 아티스트나 실제 곡 모방은 피한다.

핵심 문장:

```text
급등주는 BUY가 쏟아지고, 급락주는 SELL이 폭포처럼 내려오는 차트 밈 리듬게임.
```

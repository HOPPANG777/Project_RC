# StockRhythm Design Guide

작성일: 2026-06-27 KST

## 목적

StockRhythm MVP의 화면 디자인 양식을 정리한다.
이 문서는 개발 구현 방식이 아니라, 화면 톤과 UI/UX 디렉팅 기준을 정의한다.

## 디자인 키워드

| 키워드 | 설명 |
| --- | --- |
| Dark Trading UI | 어두운 거래창 분위기 |
| Rhythm Clarity | 노트와 판정선이 가장 잘 보여야 함 |
| Virtual Finance | 실제 금융 정보가 아닌 가상 정보 |
| Arcade Feedback | 판정과 콤보가 즉각적으로 반응 |
| Minimal Noise | 장식 정보는 플레이 시야를 방해하지 않음 |

## 전체 톤

| 항목 | 기준 |
| --- | --- |
| 배경 | 어두운 회색/검정 계열 |
| 주요 강조 | BUY는 초록, SELL은 빨강 |
| 정보 패널 | 거래창 느낌의 얇은 라인과 작은 숫자 |
| 판정 피드백 | 밝고 짧게 표시 |
| 실제 금융감 | 너무 현실적인 가격/종목/뉴스 표현은 피함 |

## 컬러 기준

| 용도 | 색상 방향 |
| --- | --- |
| Background | 거의 검정에 가까운 차콜 |
| Panel | 짙은 회색, 투명도 있는 박스 |
| Line | 낮은 명도의 회색/청록 라인 |
| BUY | 선명한 초록 |
| SELL | 선명한 빨강 |
| Profit | 밝은 흰색 또는 민트 계열 |
| Warning Text | 낮은 채도의 노랑 또는 회색 |

색상은 실제 증권 앱처럼 너무 딱딱하지 않게, 리듬 게임처럼 반응성이 느껴지게 사용한다.

## 타이포 기준

| 위치 | 기준 |
| --- | --- |
| Title | 크고 간결하게 |
| Stage Name | 게임 중 상단 또는 좌측에 명확히 |
| Profit / Combo | 숫자가 잘 읽히는 굵은 스타일 |
| 판정 텍스트 | PERFECT / GREAT / GOOD / MISS를 짧게 표시 |
| 안전 문구 | 작지만 읽을 수 있게 |

폰트 방향:

- 숫자는 고정폭 또는 디지털 UI에 가까운 느낌
- 본문 문구는 과하게 장식적이지 않은 산세리프
- 한 화면에 너무 많은 글자를 넣지 않음

## 화면별 디자인 기준

### Title

| 항목 | 기준 |
| --- | --- |
| 핵심 | 게임 이름과 가상 차트 리듬 게임 콘셉트 전달 |
| 배경 | 어두운 차트/캔들 실루엣 |
| 버튼 | Start를 가장 강조 |
| 문구 | 안전 문구를 하단에 작게 표시 |

### Stage Brief

| 항목 | 기준 |
| --- | --- |
| 핵심 | SAMSU의 분위기 전달 |
| 정보 | Drop / Rebound / Switch 같은 짧은 키워드 |
| 버튼 | Play 강조 |
| 장식 | 가상 종목 카드처럼 구성 가능 |

### Tutorial Overlay

| 항목 | 기준 |
| --- | --- |
| 핵심 | 초록 = BUY, 빨강 = SELL |
| 형태 | 짧은 오버레이 |
| 시간 | 길게 붙잡지 않음 |
| 문구 | 3줄 이하 |

### Gameplay

| 항목 | 기준 |
| --- | --- |
| 핵심 | 노트, 판정선, BUY/SELL이 최우선 |
| 정보 | Profit, Combo, Stage Name만 우선 |
| 장식 | NEWS/BID/ASK/보조 차트는 낮은 대비 |
| 안전 문구 | 하단에 작게 유지 |

Gameplay 화면 우선순위:

1. 판정선
2. 캔들/노트
3. BUY/SELL 방향
4. 판정 피드백
5. Profit / Combo
6. 장식 정보

### Result

| 항목 | 기준 |
| --- | --- |
| 핵심 | Accuracy, MaxCombo, Profit |
| 강조 | Profit은 크지만 실제 수익처럼 보이지 않게 |
| 버튼 | Retry를 가장 강조 |
| 문구 | PROFIT은 게임 점수라는 문구 포함 |

## 컴포넌트 양식

| 컴포넌트 | 기준 |
| --- | --- |
| 버튼 | 각진 거래창 UI 느낌, 과한 둥근 모서리 금지 |
| 패널 | 얇은 테두리, 낮은 투명도 |
| 노트 | 캔들 형태 유지 |
| 판정선 | 밝고 명확한 수평선 |
| 판정 텍스트 | 중앙 근처에 짧게 등장 후 사라짐 |
| 안전 문구 | 화면 하단 고정 또는 결과 화면 하단 |

## 금지/주의 사항

- 실제 회사 로고처럼 보이는 요소 금지
- 실제 주가, 실제 종목 코드처럼 보이는 값 금지
- 투자 조언처럼 읽히는 문구 금지
- 장식 패널이 노트 가독성을 방해하지 않도록 주의
- 지나치게 복잡한 거래창 UI 금지
- Title이나 Result에서 실제 수익 인증처럼 보이는 연출 금지

## MVP 디자인 완료 기준

- 처음 보는 사람이 화면만 보고 BUY/SELL 리듬게임임을 이해한다.
- 노트와 판정선이 가장 먼저 눈에 들어온다.
- Profit이 실제 수익이 아니라 점수임을 알 수 있다.
- SAMSU가 실제 종목이 아니라 가상 스테이지처럼 보인다.
- Retry 버튼이 결과 화면에서 가장 쉽게 보인다.

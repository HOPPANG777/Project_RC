# StockRhythm Direction Brief

작성일: 2026-06-27 KST
최근 확정: 2026-06-27 KST

## 핵심 정의

StockRhythm은 실제 투자 시뮬레이터가 아니라, 주식 차트의 움직임을 리듬 게임 패턴으로 변환해 플레이하는 2버튼 리듬 액션 게임이다.

플레이어는 내려오는 차트형 노트에 맞춰 `BUY`와 `SELL`을 입력한다. 점수 표현은 거래소 UI 분위기에 맞춰 `SCORE`보다 `PROFIT`을 사용하되, 실제 금전 수익이 아니라 게임 점수임을 명확히 분리한다.

## MVP 확정 방향

| 항목 | 기준 |
| --- | --- |
| 첫 MVP 스테이지 | `SAMSU` |
| 장르 | 차트 콘셉트 리듬 액션 |
| 핵심 입력 | `BUY`, `SELL` 2버튼 |
| 기본 키보드 입력 | 왼쪽 Shift = BUY, 오른쪽 Shift = SELL |
| 판정 기준 | 캔들 또는 차트 오브젝트의 종가 지점이 판정선에 닿는 순간 |
| 노트 시간 단위 | 0.1초 기준 1 캔들/노드 |
| 판정 등급 | PERFECT / GREAT / GOOD / MISS |
| 점수 표기 | `PROFIT` |
| 결과 화면 우선 항목 | Accuracy, MaxCombo, Profit |
| FEVER | MVP 범위에서 제외 |
| 화면 톤 | 실제 거래창처럼 보이는 어두운 UI, 단 모든 값은 가상 정보 |
| 실제 종목 사용 | 직접 사용 금지. 패러디 또는 가상 종목명 사용 |
| 실제 차트 사용 | 원본 그대로 사용하지 않고 패턴만 참고해 변형 |
| 안전 문구 | 실제 투자 아님, 가상 차트 기반, PROFIT은 게임 점수 |

## 판정 폭

판정 폭은 노트의 기준 시점과 입력 시점 차이의 절댓값으로 계산한다.

| 등급 | 시간 폭 | 배율 | 점수 |
| --- | ---: | ---: | ---: |
| PERFECT | 40ms 이내 | 1.0 | 100 |
| GREAT | 60ms 이내 | 0.7 | 70 |
| GOOD | 100ms 이내 | 0.5 | 50 |
| MISS | 100ms 초과 또는 미입력 | 0 | 0 |

범위가 겹칠 때는 가장 높은 등급을 우선 적용한다.
예: 35ms는 PERFECT, 55ms는 GREAT, 90ms는 GOOD.

## 점수식

```text
NoteScore = 100 * JudgementMultiplier
Profit = Sum(NoteScore)
```

| 등급 | 계산 |
| --- | --- |
| PERFECT | `100 * 1.0 = 100` |
| GREAT | `100 * 0.7 = 70` |
| GOOD | `100 * 0.5 = 50` |
| MISS | `100 * 0 = 0` |

MVP에서는 콤보 보너스, FEVER 배율, 리스크 배율을 적용하지 않는다.

## SAMSU 스테이지 기준

`SAMSU`는 전자/제조풍 가상 종목을 기준으로 한 첫 MVP 스테이지다. 급락과 반등이 섞인 패턴으로 `BUY`와 `SELL` 전환을 빠르게 보여주는 것이 목적이다.

| 항목 | 기준 |
| --- | --- |
| 스테이지 성격 | 급락 후 반등, 짧은 전환 구간 |
| 주요 입력 | SELL 구간과 BUY 구간을 모두 포함 |
| 추천 길이 | 30-60초 |
| 패턴표 작성 방식 | 데이터 타입 구조 확인 후 결정 |
| 우선 검증 목표 | BUY/SELL 전환이 즉시 이해되는지 확인 |

## MVP 플레이 목표

1. 30-60초 길이의 짧은 `SAMSU` 스테이지를 만든다.
2. `BUY`와 `SELL`만으로 즉시 이해되는 조작감을 만든다.
3. 0.1초 단위 캔들/노드가 판정선에 닿는 타이밍을 명확히 보여준다.
4. 입력 결과는 PERFECT / GREAT / GOOD / MISS로 구분한다.
5. 결과 화면에는 Accuracy, MaxCombo, Profit을 우선 표시한다.
6. 실제 금융 정보처럼 보이지 않도록 종목명, 가격, 수익 표현을 모두 가상화한다.

## UI 기준

- 중앙에는 현재 스테이지의 대표 차트 경로를 크게 보여준다.
- 좌우에는 BID/ASK, NEWS, 보조 차트, 거래량풍 패널을 배치해 거래창 분위기를 만든다.
- 하단 또는 전면에는 `BUY`, `SELL`, `PROFIT`, `COMBO`를 읽기 쉽게 배치한다.
- 결과 화면에는 `Accuracy`, `MaxCombo`, `Profit` 3가지를 우선 배치한다.
- 모든 숫자는 실제 종목 값이 아니라 게임용 가상 값으로 처리한다.

## 보류 사항

- SAMSU 패턴표 데이터 타입 구조
- 캔들/노드 데이터의 필드 구성
- 모바일 입력 방식
- 음악 자동 생성 범위와 수동 제작 범위
- 배경 뉴스 이미지가 스테이지 전체 고정인지, 구간별 변화인지

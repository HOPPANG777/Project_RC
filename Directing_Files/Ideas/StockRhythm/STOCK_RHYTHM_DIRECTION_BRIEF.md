# StockRhythm Direction Brief

작성일: 2026-06-27 KST

## 핵심 정의

StockRhythm은 실제 투자 시뮬레이터가 아니라, 주식 차트의 움직임을 리듬 게임 패턴으로 변환해 플레이하는 2버튼 리듬 액션 게임이다.

플레이어는 내려오는 차트형 노트에 맞춰 `BUY`와 `SELL`을 입력한다. 점수 표현은 거래소 UI 분위기에 맞춰 `SCORE`보다 `PROFIT`을 사용하되, 실제 금전 수익이 아니라 게임 점수임을 명확히 분리한다.

## 방향성 확정

| 항목 | 기준 |
| --- | --- |
| 장르 | 차트 콘셉트 리듬 액션 |
| 핵심 입력 | `BUY`, `SELL` 2버튼 |
| 기본 키보드 입력 | 왼쪽 Shift = BUY, 오른쪽 Shift = SELL |
| 판정 기준 | 캔들 또는 차트 오브젝트의 종가 지점이 판정선에 닿는 순간 |
| 화면 톤 | 실제 거래창처럼 보이는 어두운 UI, 단 모든 값은 가상 정보 |
| 점수 표기 | `PROFIT` |
| 실제 종목 사용 | 직접 사용 금지. 패러디 또는 가상 종목명 사용 |
| 실제 차트 사용 | 원본 그대로 사용하지 않고 패턴만 참고해 변형 |
| 안전 문구 | 실제 투자 아님, 가상 차트 기반, PROFIT은 게임 점수 |

## MVP 플레이 목표

1. 30-60초 길이의 짧은 스테이지를 만든다.
2. `BUY`와 `SELL`만으로 즉시 이해되는 조작감을 만든다.
3. 캔들형 노트가 판정선에 닿는 타이밍을 명확히 보여준다.
4. 정확한 입력은 `PROFIT`과 콤보를 올리고, 실패 입력은 콤보를 끊는다.
5. 실제 금융 정보처럼 보이지 않도록 종목명, 가격, 수익 표현을 모두 가상화한다.

## MVP 우선 스테이지 후보

| 후보 | 콘셉트 | 패턴 |
| --- | --- | --- |
| `NVIVA` | AI/반도체풍 가상 종목 | 상승 캔들 중심 BUY 패턴 |
| `GAAGLE` | 검색/플랫폼풍 가상 종목 | 횡보 후 돌파 패턴 |
| `SAMSU` | 전자/제조풍 가상 종목 | 급락과 반등이 섞인 BUY/SELL 전환 패턴 |

## UI 기준

- 중앙에는 현재 스테이지의 대표 차트 경로를 크게 보여준다.
- 좌우에는 BID/ASK, NEWS, 보조 차트, 거래량풍 패널을 배치해 거래창 분위기를 만든다.
- 하단 또는 전면에는 `BUY`, `SELL`, `PROFIT`, `COMBO`, `FEVER`를 읽기 쉽게 배치한다.
- 모든 숫자는 실제 종목 값이 아니라 게임용 가상 값으로 처리한다.

## 남은 결정 사항

- PERFECT / GOOD / MISS의 판정 폭
- 콤보 보너스와 FEVER 게이지 조건
- 스테이지별 캔들 수와 길이
- 모바일 입력 방식
- 음악 자동 생성 범위와 수동 제작 범위
- 배경 뉴스 이미지가 스테이지 전체 고정인지, 구간별 변화인지

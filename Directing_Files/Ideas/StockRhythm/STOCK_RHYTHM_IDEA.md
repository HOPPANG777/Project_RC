# Stock Rhythm Game Idea

## 한 줄 컨셉

실제 주식 차트를 기반으로 AI가 음악과 스테이지를 생성하고, 플레이어는 가로형 차트 레인과 노트가 아래로 내려오는 흐름에 맞춰 `매수`와 `매도` 2버튼을 누르며 리듬 게임을 진행한다.

## 핵심 경험

플레이어는 단순히 노트를 치는 것이 아니라, 차트의 상승과 하락, 급등락, 거래량 변화, 시장 이벤트를 리듬으로 체감한다.  
좋은 타이밍에 매수하고 적절한 타이밍에 매도하면 리듬 정확도와 수익률이 함께 점수에 반영된다.

게임의 정체성은 다음과 같다.

- 실제 차트의 움직임을 음악과 노트 패턴으로 변환
- 매수와 매도만 사용하는 직관적인 2버튼 리듬 게임
- 차트 급락/급등의 원인을 백스테이지 이미지 배경으로 연출
- 장투에서 단투로 갈수록 빨라지는 시간축 기반 난이도
- 게임 재화를 걸고 플레이하는 리스크/보상 구조
- 플레이 후 해당 구간의 시장 상황을 리포트로 복기

## 기본 조작

| 버튼 | 역할 |
| --- | --- |
| 매수 | 상승 시작, 돌파, 눌림목, 저점 반등 구간에서 입력 |
| 매도 | 고점, 과열, 이탈, 급락 위험 구간에서 입력 |

플레이어는 모든 순간에 버튼을 누르는 것이 아니라, 차트 흐름을 보며 `매수`, `매도`, `관망` 중 하나를 선택해야 한다.

## 게임 화면 구조

```text
        가로형 차트 레인과 노트가 아래로 내려옴
                      |
                      v

        ------------------------------------------------
        차트 구간 1: 캔들 / 가격선 / 매수-매도 노트
        ------------------------------------------------
                      |
                      v

        ------------------------------------------------
        차트 구간 2: 캔들 / 가격선 / 매수-매도 노트
        ------------------------------------------------
                      |
                      v

--------------------------------------
              판정선

          [ 매수 ]       [ 매도 ]
```

전면에는 플레이에 필요한 요소를 배치한다.

- 가로형 차트 레인
- 차트 위에 겹쳐진 매수/매도 노트
- 판정선
- 콤보
- 점수
- 현재 포지션 상태

차트와 노트는 화면 위에서 아래로 내려오되, 각각의 차트 구간은 가로로 긴 레인 형태를 가진다.  
플레이어는 내려오는 가로형 차트 구간이 판정선에 닿는 순간 매수 또는 매도를 입력한다.

후면에는 시장 이벤트를 상징하는 이미지 배경을 배치한다.

- 금리 인상 우려
- 실적 쇼크
- 규제 이슈
- 전쟁/공급망 이슈
- 경기 침체 우려
- 패닉 셀링
- 반도체/AI 호재

## 차트 기반 리듬 생성

차트 데이터는 음악과 노트 패턴의 재료가 된다.

| 차트 요소 | 게임 반영 방식 |
| --- | --- |
| 가격 상승 | 밝은 멜로디, 매수 노트, 콤보 유지 구간 |
| 가격 하락 | 낮은 음역, 매도 노트, 위험 구간 |
| 급등 | 빠른 노트, 드롭, 보너스 구간 |
| 급락 | 고난도 패턴, 붉은 배경, 긴장감 있는 사운드 |
| 거래량 증가 | 노트 밀도 증가, 사운드 강도 증가 |
| 변동성 증가 | BPM 또는 패턴 난이도 상승 |
| 박스권 | 매수/매도 반복 리듬 |

## 난이도 구조

난이도는 크게 `시간축`과 `리스크 배율`로 나눈다.

### 시간축 난이도

장투에서 단투로 갈수록 차트가 더 빠르게 내려오고, 노트 밀도와 판정 난이도가 높아진다.

| 난이도 | 투자 스타일 | 게임 느낌 |
| --- | --- | --- |
| 장투 | 주봉/월봉 중심 | 느린 속도, 큰 추세 중심, 실수 여유 큼 |
| 스윙 | 일봉 중심 | 기본 속도, 추세 전환과 눌림목 판단 |
| 단투 | 분봉 중심 | 빠른 속도, 매수/매도 반복 증가 |
| 스캘핑 | 초단위/틱 중심 | 고속 패턴, 판정 엄격, 실수 패널티 큼 |

### 리스크 배율

레버리지 상품은 선택형 고난도 옵션으로 사용한다.  
높은 배율을 선택하면 보상도 커지지만 손실과 실패 위험도 함께 커진다.

| 모드 | 의미 | 게임 효과 |
| --- | --- | --- |
| 현물 | 1배 | 기본 보상, 기본 손실 |
| 레버리지 2X | 공격적 플레이 | 점수/재화 보상 증가, 손실 증가 |
| 레버리지 3X | 고위험 고보상 | 보상 크게 증가, 실수 패널티 크게 증가 |
| 인버스 | 하락장 공략 | 하락 구간을 수익 기회로 처리 |
| 인버스 2X | 특수 고난도 | 인버스 구조에 레버리지 리스크 추가 |

추천 구조:

```text
난이도 = 시간축
리스크 = 레버리지
```

예시:

- 장투 + 현물: 튜토리얼
- 스윙 + 현물: 기본 스테이지
- 단투 + 2X: 고난도 스테이지
- 스캘핑 + 3X: 챌린지 스테이지
- 하락장 + 인버스: 특수 스테이지

## 백스테이지 이미지 연출

하락 또는 급등의 이유를 긴 문장으로 설명하지 않고, 스테이지 뒤 배경 이미지로 표현한다.

예시:

| 시장 원인 | 배경 이미지 방향 |
| --- | --- |
| 금리 인상 | 중앙은행 회의장, 상승하는 금리 그래프, 붉은 경고등 |
| 실적 부진 | 깨진 실적 보고서, 어두운 회의실, 하락 그래프 |
| 규제 이슈 | 정부 청사, 경고 문서, 뉴스 속보 화면 |
| 공급망 문제 | 항만, 컨테이너, 멈춘 공장 |
| 경기 침체 | 텅 빈 거리, 닫힌 매장, 어두운 도시 |
| 패닉 셀링 | 붉은 거래 화면, 쏟아지는 주문창, 혼란스러운 시장 |

배경은 플레이 요소를 방해하지 않도록 다음 규칙을 적용한다.

- 배경 블러 적용
- 어두운 오버레이 적용
- 채도 낮추기
- 노트와 판정선은 항상 고대비 유지
- 긴 설명 대신 짧은 키워드만 표시

예시 키워드:

- `RATE HIKE`
- `EARNINGS MISS`
- `REGULATION`
- `SUPPLY SHOCK`
- `PANIC SELLING`

## 점수 시스템

점수는 리듬 정확도만으로 계산하지 않는다. 트레이딩 결과와 판단력도 함께 반영한다.

| 점수 요소 | 설명 |
| --- | --- |
| 리듬 정확도 | 판정선에 맞춰 정확히 입력했는가 |
| 매매 결과 | 매수 후 매도까지 수익이 발생했는가 |
| 포지션 관리 | 보유 중 무리하게 추가 매수하지 않았는가 |
| 리스크 회피 | 급락 구간에서 적절히 매도하거나 관망했는가 |
| 불필요한 매매 패널티 | 신호가 없는 구간에서 버튼을 남발하지 않았는가 |
| 난이도 배율 | 단투/스캘핑/레버리지 선택에 따른 보상 배율 |

최종 점수 예시:

```text
Final Score = 리듬 정확도 + 수익률 보너스 + 리스크 관리 보너스 + 난이도 배율 - 무리한 매매 패널티
```

## 게임 재화 시스템

플레이어는 실제 현금이 아니라 게임 재화를 걸고 스테이지를 플레이한다.

기본 흐름:

```text
게임 재화 투자
-> 스테이지 플레이
-> 리듬 정확도 + 매매 판단 + 난이도 배율 계산
-> 재화 수익 또는 손실 반영
```

재화는 주식 컨셉에 맞춰 `시드머니`로 부른다.

| 요소 | 설명 |
| --- | --- |
| 투자금 | 플레이어가 한 판에 거는 시드머니 |
| 수익 | 좋은 매수/매도 판단과 높은 정확도에 따른 보상 |
| 손실 | 실수, 무리한 매매, 급락 대응 실패에 따른 차감 |
| 레버리지 | 보상과 손실을 동시에 키우는 선택 옵션 |
| 연습 모드 | 시드머니 손실 없이 플레이 가능한 모드 |

시드머니 사용처:

- 새 종목/차트 해금
- 배경 이미지 스킨 해금
- 노트 스킨 해금
- AI 음악 생성권
- 고난도 스테이지 입장권
- 시즌 랭킹 참가비

초보 이탈을 막기 위한 안전장치:

- 하루 기본 시드머니 지급
- 튜토리얼/장투 모드는 손실 제한
- 연습 모드는 재화 손실 없음
- 첫 레버리지 플레이 시 리스크 안내
- 시드머니가 부족할 때 소액 재시작 지원

## 플레이 후 리포트

스테이지 종료 후 플레이어에게 결과를 보여준다.

- 총 점수
- 리듬 정확도
- 가상 수익률
- 시드머니 수익/손실
- 매수/매도 타이밍 평가
- 주요 하락/상승 이벤트
- 더 나은 대응 예시

게임 중에는 흐름을 끊지 않기 위해 이미지와 키워드 중심으로 보여주고, 자세한 해설은 플레이 후 리포트에서 제공한다.

## MVP 범위

초기 버전은 작게 시작한다.

1. 실제 종목 1개 선택
2. 특정 기간의 차트 데이터 불러오기
3. 차트 구간을 30~60초 스테이지로 변환
4. 매수/매도 2버튼 입력 구현
5. 간단한 룰 기반 노트 생성
6. 배경 이미지 몇 종류 수동 지정
7. 장투/스윙/단투 중 최소 2개 난이도 구현
8. 시드머니 투자와 수익/손실 계산
9. 리듬 정확도와 가상 수익률 점수 계산

## 노트 생성 초기 규칙

AI를 바로 전면에 사용하기보다, MVP에서는 룰 기반으로 안정적인 기준을 만든다.

- 단기 이동평균 돌파: 매수 노트
- 단기 이동평균 이탈: 매도 노트
- 일정 수익률 도달: 매도 노트
- 거래량 급증: 노트 밀도 증가
- 변동성 증가: 난이도 상승
- 급락 구간: 빠른 매도 노트 또는 함정 패턴

이후 AI는 다음 영역에 점진적으로 적용한다.

- 차트 분위기에 맞는 음악 생성
- 시장 이벤트 배경 이미지 생성
- 노트 패턴 난이도 조정
- 플레이 후 해설 요약

## 주의할 점

- 실제 종목과 시장 데이터를 사용할 경우 투자 조언처럼 보이지 않도록 주의한다.
- 게임 내 결과는 교육 및 엔터테인먼트 목적임을 명확히 한다.
- 하락 원인은 단정하지 않고, 복합적인 시장 요인으로 표현한다.
- 배경 이미지가 너무 강하면 노트 가독성이 떨어질 수 있다.
- 차트 레인은 가로로 길게 구성하되, 판정 흐름은 위에서 아래로 내려오게 유지한다.
- 게임 재화 보상은 실제 현금 보상처럼 오해되지 않도록 명확히 분리한다.
- AI 생성 음악과 이미지의 상업적 이용 가능 여부를 확인해야 한다.

## 방향성 요약

이 게임은 `차트의 리듬을 플레이하고, 시장의 이유를 배경으로 체험하는 매수/매도 리듬 게임`이다.

2버튼 조작으로 진입 장벽은 낮추고, 실제 차트와 시장 이벤트를 활용해 깊이를 만든다.  
핵심 재미는 버튼을 많이 누르는 것이 아니라, 언제 사고 언제 팔고 언제 가만히 있을지를 리듬 속에서 판단하는 데 있다.

# StockRhythm MVP Tasks

작성일: 2026-06-27 KST

## 1차 목표

Project_RC에서 StockRhythm의 첫 플레이 가능한 리듬 프로토타입을 만들기 위한 준비 작업 목록이다.

## 기획 정리

| 상태 | 작업 | 산출물 |
| --- | --- | --- |
| 완료 | 원본 Stock Rhythm 산출물 이관 | `Directing_Files` 내부 문서와 자산 |
| 완료 | 현재 방향성 요약 | `STOCK_RHYTHM_DIRECTION_BRIEF.md` |
| 대기 | 판정 폭 수치 확정 | PERFECT / GOOD / MISS 기준표 |
| 대기 | 콤보와 FEVER 조건 확정 | 점수 규칙표 |
| 대기 | 첫 스테이지 후보 1개 확정 | `NVIVA`, `GAAGLE`, `SAMSU` 중 선택 |

## 프로토타입 제작

| 상태 | 작업 | 기준 |
| --- | --- | --- |
| 대기 | 2D 플레이 씬 구성 | 중앙 차트 라인, 판정선, UI 패널 |
| 대기 | BUY / SELL 입력 연결 | 왼쪽 Shift, 오른쪽 Shift |
| 대기 | 캔들 노트 프리팹 제작 | 상승 캔들 = BUY, 하락 캔들 = SELL |
| 대기 | 노트 이동 로직 제작 | 정해진 속도로 판정선까지 이동 |
| 대기 | 판정 로직 제작 | 종가 지점 기준 타이밍 판정 |
| 대기 | PROFIT / COMBO 표시 | 점수와 콤보 실시간 갱신 |
| 대기 | 간단한 결과 화면 | 정확도, 콤보, PROFIT 표시 |

## 1차 완료 기준

- 30초 이상 플레이 가능한 스테이지가 있다.
- BUY / SELL 입력으로 노트를 판정할 수 있다.
- 입력 결과가 PROFIT과 COMBO에 반영된다.
- 결과 화면에서 플레이 성과를 볼 수 있다.
- 실제 투자 게임으로 오해될 수 있는 요소가 제거되어 있다.

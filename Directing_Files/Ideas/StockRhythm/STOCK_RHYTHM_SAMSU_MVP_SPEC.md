# StockRhythm SAMSU MVP Spec

작성일: 2026-06-27 KST
최근 확정: 2026-06-27 KST

## 목적

`SAMSU`를 StockRhythm의 첫 MVP 스테이지 기준으로 삼는다.
이 문서는 구현 방식이 아니라, 개발자가 참고할 플레이 규칙과 결과 기준을 정리한 기획 사양이다.

## 스테이지

| 항목 | 기준 |
| --- | --- |
| 스테이지명 | `SAMSU` |
| 종목 성격 | 전자/제조풍 가상 종목 |
| 실제 종목 여부 | 실제 종목 아님 |
| 주요 감정 | 급락, 반등, 전환 |
| 패턴 방향 | SELL 구간과 BUY 구간을 모두 포함 |
| 패턴표 작성 방식 | 후순위. 개발자가 지정한 양식 확정 후 작성 |

## 노트 속도

```text
0.1초 = 1 캔들/노드
```

MVP의 시간 해상도는 0.1초 단위로 잡는다.
즉, 30초 스테이지는 최대 300개의 캔들/노드 기준선을 가질 수 있다.

실제 노트가 모든 노드에 배치될 필요는 없다.
패턴표는 개발자가 지정한 양식을 받은 뒤, 필요한 노드에만 `BUY` 또는 `SELL` 입력을 배치한다.

## 판정

판정은 노트 기준 시점과 플레이어 입력 시점 차이의 절댓값으로 계산한다.

| 등급 | 조건 | 점수 |
| --- | --- | ---: |
| PERFECT | 40ms 이내 | 100 |
| GREAT | 60ms 이내 | 70 |
| GOOD | 100ms 이내 | 50 |
| MISS | 100ms 초과 또는 미입력 | 0 |

겹치는 범위에서는 가장 높은 등급을 적용한다.

```text
0ms-40ms    -> PERFECT
40ms-60ms   -> GREAT
60ms-100ms  -> GOOD
100ms 초과  -> MISS
```

## 점수

```text
NoteScore = 100 * JudgementMultiplier
Profit = Sum(NoteScore)
```

| 등급 | 배율 | 점수 |
| --- | ---: | ---: |
| PERFECT | 1.0 | 100 |
| GREAT | 0.7 | 70 |
| GOOD | 0.5 | 50 |
| MISS | 0 | 0 |

MVP에서는 FEVER, 리스크 배율, 콤보 보너스를 점수식에 넣지 않는다.

## 콤보

- PERFECT, GREAT, GOOD은 콤보를 1 증가시킨다.
- MISS는 콤보를 0으로 초기화한다.
- 결과 화면에는 가장 높았던 콤보를 `MaxCombo`로 표시한다.

## Accuracy

MVP의 Accuracy는 우선 판정 배율 기반으로 계산한다.

```text
Accuracy = Sum(JudgementMultiplier) / TotalNoteCount * 100
```

예시:

```text
PERFECT 10개, GREAT 5개, GOOD 5개, MISS 0개
Accuracy = (10*1.0 + 5*0.7 + 5*0.5) / 20 * 100
         = 80%
```

추후 리듬게임식 정확도 계산식이 필요하면 개발자와 협의해 교체한다.

## 결과 화면

MVP 결과 화면은 아래 세 가지만 우선 채택한다.

| 항목 | 의미 |
| --- | --- |
| Accuracy | 전체 입력 정확도 |
| MaxCombo | 최고 연속 성공 수 |
| Profit | 최종 점수 |

## 제외 범위

| 항목 | 처리 |
| --- | --- |
| FEVER | MVP에서 제외 |
| 리스크/레버리지 배율 | MVP에서 제외 |
| 실제 종목명/로고/가격 | 사용 금지 |
| 실제 투자 조언처럼 보이는 문구 | 사용 금지 |

## 개발자 결정 영역

아래 내용은 이 문서에서 확정하지 않는다.

- Unity 씬 구조
- 노트 이동 구현 방식
- 오디오 싱크 방식
- 입력 처리 구조
- 패턴 데이터 타입과 파일 형식
- 코드 구조와 클래스 분리
- 보정 옵션

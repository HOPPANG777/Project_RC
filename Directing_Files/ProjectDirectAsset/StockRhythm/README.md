# StockRhythm Project Direct Assets

이 폴더는 StockRhythm 기획에 필요한 참고 자산과 원본 산출물을 관리한다.

## 포함 파일

- `Stock Rhythm 컨셉 기획서.docx`
- `CONCEPT_IMAGES.md`
- `concept-images/`
- `ASSET_MANIFEST.md`
- `SourceMeta/.obsidian/`

## 사용 기준

- `concept-images`의 이미지는 기획 참고와 방향성 공유용이다.
- 실제 게임 리소스로 사용할 때는 해상도, 저작권, UI 가독성, 실제 금융 정보 오해 가능성을 다시 검토한다.
- `SourceMeta`는 원본 작업 환경 기록 보관용이며 제작 기준 문서로 사용하지 않는다.

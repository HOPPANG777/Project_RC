# Directing Files Index

작성일: 2026-06-27 KST

이 폴더는 Project_RC에서 기획, 방향성, 참고 자산, 변경 로그만 관리하는 공간이다.
이번 정리는 `Stock Rhythm` 원본 산출물을 `Directing_Files` 내부 양식에 맞게 재배치한 것이다.

## 관리 원칙

- 모든 신규 관리 파일은 `Directing_Files` 내부에만 둔다.
- 원본 `Stock Rhythm` 폴더와 Unity 프로젝트 본문은 수정하지 않는다.
- 원본 문서는 보존용으로 복사하고, 현재 프로젝트 진행 기준은 새 정리 문서에서 관리한다.
- 실제 투자, 실제 종목, 실제 수익으로 오해될 수 있는 표현은 게임용 가상 정보로 분리한다.

## 폴더 구성

| 폴더 | 용도 |
| --- | --- |
| `Ideas/StockRhythm` | StockRhythm 기획 원문, 방향성 요약, MVP 작업 문서 |
| `ProjectDirectAsset/StockRhythm` | Word 기획서, 콘셉트 이미지, 이미지 제작 프롬프트, 원본 메타 보관 |
| `UpdateLog/StockRhythm` | StockRhythm 단일 업데이트 로그 |

- `STOCKRHYTHM_FILE_INVENTORY.md`: 원본 파일별 배치 현황

- `Ideas/StockRhythm/STOCK_RHYTHM_PLAY_FLOW_UIUX.md`: 플레이 흐름과 UI/UX 화면 구성
- `Ideas/StockRhythm/STOCK_RHYTHM_DESIGN_GUIDE.md`: MVP 디자인 양식과 화면 톤 기준
- `Ideas/StockRhythm/STOCK_RHYTHM_SCENE_ELEMENT_LIST.md`: 씬별 후보 요소 목록

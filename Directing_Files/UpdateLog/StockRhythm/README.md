# StockRhythm Update Log

이 폴더는 StockRhythm 관련 변경 로그와 Project_RC 이관 내역을 관리한다.

## 포함 파일

- `PROJECT_UPDATE_LOG.md`: Stock Rhythm 원본 프로젝트 변경 로그
- `STOCK_RHYTHM_DIRECTING_MIGRATION_LOG.md`: Project_RC의 `Directing_Files` 내부 이관 로그
- `STOCK_RHYTHM_MVP_DECISION_LOG.md`: MVP 확정 사항 기록

## 기록 기준

- 원본에서 발생한 변경은 원본 로그를 보존한다.
- Project_RC 내부 관리 변경은 별도 이관 로그에 기록한다.
- 게임 방향과 제작 기준 확정 사항은 MVP 결정 로그에 기록한다.
- Unity 구현 작업이 시작되면 Unity 파일 변경 로그와 Directing 변경 로그를 분리한다.
